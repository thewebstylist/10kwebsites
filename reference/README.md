# Reference Folder

Drop anything here that should inform a site design request. Everything committed
to this folder travels with the repo, so **every** future session can see it —
you don't have to re-upload it each time.

When you start a design request, just point to it, e.g.:

> "Design my homepage using the brand material in `/reference/brand` and the
> layouts I liked in `/reference/inspiration`."

## What goes where

| Folder | Put this here |
|--------|---------------|
| `brand/` | Logos, color palette, fonts, brand/style guide, voice & tone notes |
| `inspiration/` | Screenshots or links to sites/layouts you like (and what you like about them) |
| `content/` | Real copy — headlines, about text, service descriptions, testimonials |
| `assets/` | Photos, icons, illustrations, and other media to use on the site |

## Tips

- **Images & screenshots** are great — I can read them directly.
- For **links**, drop them in a `.md` file (e.g. `inspiration/links.md`) with a
  one-line note on what to notice about each.
- The more specific the reference, the closer the first draft lands.

## One-off vs. persistent

- Use the **`+` button** in the chat composer to attach a file to a single
  message (not saved for later).
- Use **this folder** for anything you'll reference more than once — brand
  assets, standing content, recurring inspiration.
